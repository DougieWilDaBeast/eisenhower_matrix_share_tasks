# Eisenhower Matrix: shared-task links

When someone shares a task from **Eisenhower Matrix**, an offline-first Android to-do app by
[Will Douglas](https://github.com/DougieWilDaBeast), the link points at
[`share.html`](share.html). The page, served with GitHub Pages, opens the task in the app if it's
installed, and otherwise sends the person to the app on
[Google Play](https://play.google.com/store/apps/details?id=com.willjkdouglas.eisenhower_matrix).

The app's source code is private.
